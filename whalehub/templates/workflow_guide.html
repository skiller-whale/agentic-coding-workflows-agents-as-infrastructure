Each .whalehub/*.md file defines one agent: YAML settings followed by Markdown instructions.

Example

---
name: Review issue
model: eu.anthropic.claude-haiku-5-5
trigger: manual
tools: [ReadIssue]
max_turns: 8
timeout_seconds: 120
---
Read issue #{{ '{{ whalehub.event.issue.number }}' }} with ReadIssue.
Summarize one useful next step.
If no issue number was supplied, explain that an issue must be selected.

Settings

nameDisplay name.
modelClaude Bedrock model ID.
trigger
  • manual: start in Runs.
  • issue_created: run when an issue is created.
toolsAvailable tools; [] enables none.
max_turnsOptional positive integer. Overrides the runner's turn limit (12 unless reconfigured).
timeout_secondsOptional positive integer. Overrides the execution timeout in seconds (180 unless reconfigured). Includes tool execution.

Issue fields

Fields under whalehub.event.issue:

  • number: selected issue number.
  • title: issue title.
  • body: issue description.
  • labels: list of labels.
  • comments: list of comments.

Available tools

Use these groups in tools, for example tools: [Read, Edit, Bash]. Whalehub expands each group into the listed Claude Code tools before starting the agent.

Workflow groupClaude Code tools and purpose
ReadRead, Glob, Grep
Read files, find filenames and search file contents.
EditEdit, Write, NotebookEdit
Edit existing files, create files and edit notebooks.
BashBash
Run shell commands, tests and Git.
SubagentsAgent
Delegate work to Claude Code's built-in subagents.

Whalehub issue tools

ToolPurpose
ReadIssueRead one issue's current title, body, labels and comments: {"issue_number": 1}.
ReadIssuesRead all current issues, including labels and comments. No arguments.
CreateIssueCreate an issue: {"title": "Your title", "body": "Your description"}. Returns its number and content.
SetIssueLabelsReplace labels: {"issue_number": 1, "labels": ["maintenance"]}. [] clears them.
AddIssueCommentPost a comment: {"issue_number": 1, "body": "Your report"}.
